context (기억의 창)

- memory.md
- 작업을 수행중인 ai가 이전 작업을 이어서 할 수 있게 기록하는 창

(v) skills(능력, 복수로 생성해야 함) - 요리 기술

- q스킬
- w스킬
- e스킬
- r스킬

(v) agent(역할) - 요리사

- 전사 (q, w 스킬을 가짐)(공격 역할)
- 서포터(w, r 스킬을 가짐)(보조 역할)

(동적으로 생성하기) workflow (작전) - 요리 레시피

- agent 끼리 협업을 하게 만들기
- ex) 부산 침략 작전 :
  1. 전사가 공격
  2. 서포터가 보조
  3. 전사가 공격
- skill을 먼저 작성해두고 ai에게 workflow 작성을 맡기기

orchestrator (지휘자) - 주방장

- workflow 여러 개를 만들어 ai에게 제작을 맡기거나, 사람(개발자)이 담당하기

사람이 확인할 문서

1. Prd (프로젝트 계획서) - 프로젝트의 비즈니스를 파악하여 제작하기 : 회의 내용이나 기능 정의, 스토리보드를 제작하여 ai 동적 생성
2. Tech(기술 정의서), 코드 컨벤션
3. task (임무) - 1, 2번의 문서를 바탕으로 ai가 해야 할 임무 지정 : Context(요약본) 작성(memory.md)
